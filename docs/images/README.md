# README 用のスクリーンショット置き場

README.md から次の名前で参照しています。撮ったらこの名前で保存してください（PNG）。

| ファイル名 | 撮る画面 |
| --- | --- |
| `02-pages-source.png` | Settings → Pages の「Source: GitHub Actions」 |
| `10-pr-list.png` | Pull requests の一覧 |
| `11-pr-files.png` | プルリクの「Files changed」タブ |
| `12-pr-merge.png` | 「Merge pull request」ボタン |
| `13-branch-protection.png` | Settings → Rules の main の保護設定 |

Wiki の「投稿のしかた」の画像は `site/img/guide/` にあります。GitHub の画面のイメージ図（`*.svg`）を、実際のスクリーンショットに差し替えてもかまいません（同じ名前で `.png` にした場合は、記事の中の拡張子も直してください）。
