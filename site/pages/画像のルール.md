記事に画像や動画を入れるときのルールです。むずかしいことはありません。次の **3つだけ** 守ってください。

## 守ること（3つだけ）

1. **画像は X（旧 Twitter）のポスト、動画は YouTube で貼る**
   この Wiki には、画像を直接のせられません。ほかの画像サイトの画像も表示されません。
2. **人のポストや動画を貼るときは、ルールを守っているものだけ**
   だれかの絵や画像を勝手に転載したポストは貼らないでください。
3. **「外して」と言われたら外す**
   ポストや動画の持ち主、運営から頼まれたら、記事から外します。

迷ったときは、貼らないでください。

## 貼っていいもの・だめなもの

| 貼るもの | 貼っていい？ |
| --- | --- |
| 自分で撮ったマイクラのスクリーンショット（自分で X にポストしたもの） | ○ |
| 自分の配信のアーカイブや切り抜き（YouTube） | ○ |
| 配信者やプレイヤーが自分でしたポスト・動画（アイコン入りの告知など） | ○ |
| 公式のお知らせのポスト | ○ |
| だれかの絵や画像を、勝手に転載しているポスト・動画 | × |
| 顔写真や、本名・住所・学校がわかるもの | × 自分のものでもだめ |
| ほかの人の拠点の場所（座標）がわかるもの | × その人がいいと言ったときだけ ○ |

## 貼り方

### X のポスト・YouTube の動画

1. 貼りたいポストや動画の「共有」から、**リンクをコピー** する
2. 編集画面の「**X・YouTube**」ボタンを押して、`https://x.com/` のところに、コピーした URL を貼り付ける

できあがりは、こんな形になります。

```
[[埋め込み:https://x.com/ユーザー名/status/1234567890]]
[[埋め込み:https://www.youtube.com/watch?v=xxxxxxxxxxx]]
```

- 1 行に 1 つずつ書きます
- 記事では、はじめは「表示する」ボタンだけが出ます。見る人がボタンを押すと、ポストや動画が表示されます（押すまで X や YouTube には何も送られません）

### プレイヤーのスキンの顔

MCID を書くと、その人が今使っているスキンの顔が出ます。押すと NameMC（スキンの情報サイト）が開きます。

```
[[スキン:MCID]]        … 小さい顔と名前
[[スキン:MCID|64]]     … 顔だけ（数字は大きさ。16〜128）
```

編集画面の「**スキン**」ボタンでも入れられます。スキンを変えると、Wiki の顔も自動で変わります。

## 気をつけること

- **ポストや動画が消されると、Wiki でも表示されなくなります**（「表示できませんでした」と出ます）
- **鍵アカウント（非公開）のポストは、ほかの人には表示されません**
- **画像や動画は、この Wiki のライセンス（CC BY-SA 4.0）の対象外** です。それぞれの持ち主のものなので、ほかで使いたいときは持ち主に聞いてください
- **「表示する」を押すと、見ている人の情報が X や YouTube に伝わります**。スキンの顔は mc-heads.net というサイトから読み込みます
