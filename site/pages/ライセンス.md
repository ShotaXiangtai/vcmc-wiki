## CC BY-SA 4.0 とは

「クリエイティブ・コモンズ 表示-継承 4.0 国際」というライセンスで、Wikipedia と同じものです。次の決まりを守れば、コピー・配布・書き換えができ、お金が関わる使い方（収益化した動画や配信を含む）もできます。

- **表示（BY）**：出典（ページ名・URL）とライセンスを書く。書き換えたときは、そのことも書く
- **継承（SA）**：書き換えたものを公開するときは、同じ CC BY-SA 4.0 にする
- **追加の制限をしない**：使う人に、ライセンス以外の制限をかけない

正式な内容は、[ライセンスの説明（日本語）](https://creativecommons.org/licenses/by-sa/4.0/deed.ja) と [法的条項](https://creativecommons.org/licenses/by-sa/4.0/legalcode.ja) を見てください。

## 記事を使うとき

### 出典の書き方

転載するときや、動画・配信で記事を見せるときは、次のように書いてください。

```
出典：VoiceMC Wiki「はじめかた」 https://shotaxiangtai.github.io/vcmc-wiki/?p=はじめかた
ライセンス：CC BY-SA 4.0 https://creativecommons.org/licenses/by-sa/4.0/deed.ja
```

- 作者は「VoiceMC Wiki の投稿者」と書けば十分です。投稿者の一覧は、各ページの「履歴」タブ（GitHub）で見られます
- 書き換えて使ったときは「（一部改変）」などと書き足してください
- 動画や配信では、概要欄や画面の中に書いてください

### 書き換えたものを公開するとき

記事を書き換えたものや、記事をもとに作った文章を公開するときは、同じ CC BY-SA 4.0 で公開してください。

### 短く引用するとき

著作権法の「引用」のルール（出典を書く、自分の文章が主で引用は従、など）を守れば、ライセンスとは関係なく引用できます。

## 記事を書くとき

### 投稿してよいもの

- 自分で書いた文章
- 自分で撮った Minecraft のスクリーンショット（Minecraft の利用ガイドラインの範囲で使えます）
- 下の表で「○」のもの

ゲームの仕様（数値・レシピ・手順などの事実）は、自分の言葉でまとめれば書けます。ほかのサイトの文章をそのままコピーするのはやめてください。

### ほかのところから持ってくるとき

| 持ってくるもの | 使える？ | 条件 |
| --- | --- | --- |
| Wikipedia の文章 | ○ | 記事の中に、出典（記事名と URL）と「CC BY-SA 4.0」を書く |
| CC BY・CC BY-SA・CC0 の文章や画像 | ○ | 記事の中に、出典とライセンスを書く |
| Minecraft Wiki の文章 | × | 営利目的の禁止（NC）が付いたライセンスなので、一緒に使えない |
| 「NC」や「ND」が付いたクリエイティブ・コモンズのもの | × | CC BY-SA 4.0 と一緒に使えない |
| 攻略サイト・ブログ・動画などの文章や画像 | × | 権利を持つ人の許可がない限り使えない |
| ほかの人が撮ったスクリーンショット | △ | 撮った人の許可を取り、そのことを記事に書く |

### 配信者・プレイヤーのアイコンなど、人の画像を使うとき

配信者のアイコン・立ち絵・似顔絵などには、本人やイラストを描いた人の権利（著作権・肖像権など）があります。CC BY-SA 4.0 で公開することはできないので、次のルールを守るときだけ使えます。

- **本人の許可を取る**。イラストの場合は、**描いた人の許可**も必要です（本人が「使ってよい」と言っても、描いた人が許していないことがあります）
- プルリクエストの説明欄に、許可を取ったこと（いつ・どこで・だれに）を書く
- 画像のすぐ下に、次のように書く

```
画像：○○さん（本人の許可を得て掲載。CC BY-SA 4.0 の対象外）
```

- 本人や描いた人から削除の依頼があったら、すぐに消します
- 本名・顔写真など、個人が特定できる画像は使いません

かわりに、本人がゲーム内で使っているスキンを自分で撮ったスクリーンショットを使うと、許可の手間が少なくなります。それでも本人が嫌がる場合は使わないでください。

### 外部の画像を貼るとき

- 画像の近くに、出典とライセンスを書いてください
- 画像を置いているサイトに、記事を見た人の情報（IP アドレスなど）が伝わることがあります。信頼できる場所の画像だけを使ってください

## 投稿した人の権利

- 投稿した文章の著作権は、投稿した人に残ります。投稿した人は、CC BY-SA 4.0 で使ってよいと許可したことになります（取り消せません）
- 自分の投稿を、自分のブログなどで別の条件で使うのは自由です
