GitHub アカウントがあれば、だれでもページの編集を**提案**できます。提案は管理者が確認して、承認されると公開されます。

> パソコンでの手順です。スマホでもできますが、GitHub のアプリが開いた場合は、ブラウザで開き直してください。

## 準備：GitHub アカウントを作る

[GitHub](https://github.com/signup) で無料のアカウントを作ります（メールアドレスが必要です）。GitHub の決まりで、13歳未満の人はアカウントを作れません。

GitHub のユーザー名は、だれが投稿したかの記録として公開されます。

## 1. Wiki で書いてプレビューする

- 直したいページを開いて、上の「編集」タブを押します
- 新しいページは、左のメニューの「新しいページを作る」か、赤いリンクから作れます
- 書き方は [[Wikiの書き方]] を見てください。「プレビュー」タブで見た目を確認できます

## 2. 本文をコピーして GitHub を開く

編集画面の下にある「① 本文をコピーする」を押してから、「② GitHub の編集画面を開く」を押します。GitHub が新しいタブで開きます。

![Wiki の編集画面の「本文をコピーする」と「GitHub の編集画面を開く」のボタン](img/guide/1-copy.png)

GitHub にログインしていないときは、ログインの画面が出るのでログインしてください。

## 3. はじめてのときだけ：Fork（フォーク）する

「Fork this repository」というボタンが出たら押します。自分専用のコピー（fork）が作られて、編集画面に進みます。2回目からは出ません。

![「Fork this repository」のボタンを押す](img/guide/2-fork.svg)

## 4. 貼り付けて「Commit changes...」を押す

本文の欄を全部選んで（Ctrl+A）、コピーした本文を貼り付けます（Ctrl+V）。新しいページのときは、空の欄に貼り付けます。ファイル名が「ページ名.md」になっていることも確かめてください。

貼り付けたら、右上の緑のボタン「Commit changes...」を押します。

![本文を貼り付けて「Commit changes...」を押す](img/guide/3-paste.svg)

## 5. 「Propose changes」を押す

出てきた画面の「Extended description」に、何を変えたかを書いておくと、管理者が確認しやすくなります（書かなくてもかまいません）。緑のボタン「Propose changes」を押します。

![何を変えたかを書いて「Propose changes」を押す](img/guide/4-propose.svg)

## 6. 「Create pull request」を押す

変更の確認画面になります。赤い行が消した部分、緑の行が足した部分です。緑のボタン「Create pull request」を押します。

![変更を確認して「Create pull request」を押す](img/guide/5-compare.svg)

## 7. 確認項目にチェックして投稿する

説明欄の「確認」にある3つの `[ ]` を、すべて `[x]` に書き換えます（[[利用規約]] と [[ライセンス]] への同意です）。最後にもう一度「Create pull request」を押すと、投稿は完了です。

![確認項目を [x] にして「Create pull request」を押す](img/guide/6-pr.svg)

## 8. 承認を待つ

管理者が内容を確認して承認（マージ）すると、数分で Wiki に反映されます。投稿したプルリクエストは、左のメニューの「承認待ちの投稿」から見られます。管理者からコメントが来ることもあるので、GitHub の通知も見てください。

## うまくいかないとき

| 困ったこと | どうする |
| --- | --- |
| 「本文をコピーする」でエラーが出る | 表示された理由（ページ名・使えない記述など）を直してから、もう一度押す |
| 自動でコピーできなかった | 本文が選ばれた状態になるので、Ctrl+C（スマホは長押し →「コピー」）でコピーする |
| スマホで GitHub のアプリが開いた | ブラウザで開き直す |
| 「Commit changes...」のボタンがない | ログインしているか確かめる。「Fork this repository」が出ていたら押す |
| プルリクエストのチェック（Validate）が赤い | 確認項目を3つとも `[x]` にしたか、使えない記述がないかを確かめる。説明欄を直すと、もう一度チェックされる |

わからないことは、[公式 Discord](https://discord.gg/UC7Zgvkps8) で聞いてください。
