むずかしい文章が苦手な人のための、書き方のかんたん版です。
くわしくは [[Wikiの書き方]] にあります。

## ひとことで言うと

**ふつうに文章を書けば OK。ちょっとだけ記号を使うと、見出しや太字になるよ。**

## これだけ覚えれば OK

| こう書くと | こうなる |
| --- | --- |
| `## 見出し` | 大きな見出し |
| `**太字**` | **太字** |
| `- りんご` | ・りんご（箇条書き） |
| `[[はじめかた]]` | ほかのページへのリンク |
| `[[埋め込み:URL]]` | X のポストや YouTube の動画 |
| `[[スキン:MCID]]` | スキンの顔 |

- 覚えられなくても大丈夫。編集画面の上のボタンを押せば入ります
- 「**プレビュー**」で、どう見えるか確かめられます
- 改行はそのまま改行になります。空いた行をはさむと、段落が分かれます

## 赤いリンクって？

まだないページへのリンクです。押すと、そのページを作れます。

## ページの名前のきまり

- 60文字まで
- 「/」や「.」などの記号は使えません

## ダメなこと

- ほかのサイトの文章をコピーしない（自分の言葉で書く）
- 人がいやがることは書かない（[[利用規約（かんたん版）]]）
- 画像は X のポストで貼る（[[画像のルール（かんたん版）]]）
