VoiceMC で遊ぶときのルールです。みんなが気持ちよく遊べるように、参加する前に必ず読んでください。

> このページは、公式サイトの [ルール＆ガイドライン](https://www.vcmc.jp/rules.html) をもとにまとめたものです。内容がちがうときは、**公式サイトのルールが優先**されます。ゲームの中では `/rules` でも確認できます。

## 禁止事項

次のことは禁止です。違反が見つかった場合は、**警告**、または**サーバーからの退出・BAN** の対象になります。

### 配信について

- 配信者ロールを持っていない人が、自分の配信 URL を貼ること

### プレイ・チャットについて

- Simple Voice Chat を入れずに、メインワールドに参加すること
- 外部のボイスチャット（Discord など）で話しながら遊ぶこと（VoiceMC 公式 Discord のボイスチャットは OK）
- おたがいの合意がない PvP
- 荒らし・迷惑行為
- チート・不正行為
- 卑猥な、または公序良俗に反する建築・発言
- 特定の思想・宗教・政治的な主張を含む建築・発言
- 運営の指示に従わないこと
- ほかのプレイヤーの許可なく、建築物を壊すこと
- バグ・不具合・エクスプロイトを悪用すること
- PvP 補助や自動化マクロなど、不正な MOD やスクリプトを使うこと
- ほかのプレイヤーへの誹謗中傷・煽り
- スパム・無断の宣伝
- 個人情報を共有したり、晒したりすること
- ピザにパイナップルを乗せること 🍍

## プレイガイド（おすすめ）

強制ではありませんが、みんなが気持ちよく遊べるように協力をお願いします。

### コミュニケーション

- ていねいな言葉づかいと、節度ある態度を心がけましょう
- 初めて会ったプレイヤーには、軽くあいさつを
- いやな発言を見かけても過度に反応せず、運営に報告しましょう

### プレイのマナー

- ほかの人の建築物は、壊さず・荒らさず・大切にしましょう
- みんなで使う施設やチェストは、ゆずり合って使いましょう
- AFK（放置）するときは、安全な場所に移動しておくと安心です
- Mob をたくさん飼う・大きな装置を作るなど、サーバーに負荷がかかることはほどほどに

### 配信・撮影するとき

- 配信中も、ほかのプレイヤーへの気配りを忘れずに
- 配信・撮影をするときは、コマンドで周りに分かるように表示しましょう

| やること | コマンド |
| --- | --- |
| 配信を始める | `/stream on` |
| 配信を終える | `/stream off` |
| 撮影を始める | `/rec on` |
| 撮影を終える | `/rec off` |

- 視聴者にも、ルールを簡単に伝えてもらえると助かります
- 配信タイトルにサーバー名を入れても OK です

### 運営への協力

- 不具合やバグを見つけたら、くわしい内容を添えて運営に報告してください
- ルールや仕様についての質問は、気軽にスタッフまで
