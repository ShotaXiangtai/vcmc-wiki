このページでは、VoiceMC に初めて参加するときの手順を説明します。

> 対応しているバージョンやお知らせは、[公式サイト](https://www.vcmc.jp/) で最新の情報を確認してください。

## 参加のしかた

1. Minecraft（Java版）を起動する
2. 「マルチプレイ」→「サーバーを追加」を選ぶ
3. サーバーアドレスに次の文字を入れて「完了」を押す

```
vcmc.jp
```

4. 一覧に出たサーバーを選んで「サーバーに接続」を押す

### ボイスチャットを使うには

VoiceMC は **Simple Voice Chat** に対応しています。近くのプレイヤーと声で話したいときは、Simple Voice Chat の Mod を入れてから参加してください。Mod が無くても遊ぶことはできます。

## 最初にやること

- [[サーバーのルール]] を読む
- ロビーの案内を確認する
- わからないことは [[よくある質問]] を見る

## 便利なコマンド

| コマンド | できること |
| --- | --- |
| `/hub` | ロビーに戻る |
| `/rules` | ルールを表示する |
| `/tweet` | タブの名前の横に出す、ひとこと（つぶやき）を書く画面を開く |
| `/tweet ひとこと` | つぶやきを直接書く（20 文字まで） |
| `/tweet clear` | つぶやきを消す |

※ コマンドの一覧は、公式サイトの「コマンドガイド」も見てください。
