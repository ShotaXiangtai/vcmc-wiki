## ひとことで言うと

**この Wiki の文章は、「VoiceMC Wiki より」と書けば、だれでも自由に使っていいよ。**

## 自由に使っていいもの・ダメなもの

| もの | 自由に使っていい？ |
| --- | --- |
| 記事の文章 | ○ 出どころを書けば OK |
| 記事の中の X のポスト・YouTube の動画 | × 持ち主のもの。使いたいときは持ち主に聞く |
| スキンの顔 | × それぞれのプレイヤーのもの |
| VoiceMC のロゴ・アイコン | × 運営のもの |
| マイクラの画面・名前など | × Mojang のもの |

## 文章を使うときの約束（2つだけ）

1. **出どころを書く**
   こんなふうに書けば OK です。
2. **書きかえて公開するときは、同じルール（CC BY-SA 4.0）にする**
   「だれでも使っていいよ」を、次の人につないでいくイメージです。

```
出典：VoiceMC Wiki「はじめかた」 https://wiki.vcmc.jp/?p=はじめかた（CC BY-SA 4.0）
```

- 動画や配信で使っても OK です（収益化していても OK）
- 動画や配信では、概要欄や画面に出どころを書いてください

## 自分が書くときの約束

- 自分の言葉で書く（ほかのサイトの文章をコピーしない）
- ゲームの数字やレシピなどの「事実」は、自分の言葉でまとめれば OK
- Wikipedia の文章は、出どころを書けば使って OK
- Minecraft Wiki の文章はダメ（ルールが合わないため）
- 画像や動画は [[画像のルール]] を見てね

## あなたが書いた文章は

- 書いた人のものです。でも、だれでも上の約束で使えるようになります
- あとから取り消すことはできません
- 自分のブログなどで、自分の文章を別のルールで使うのは自由です
