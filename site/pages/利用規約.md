## 第2条 投稿と承認

1. 投稿には GitHub のアカウントが必要です。投稿者は、GitHub の利用規約（13歳以上であることなど）にも従ってください。
2. 投稿は、運営が確認して承認（マージ）したものだけが公開されます。運営は、理由を示さずに投稿を承認しないことができます。
3. 運営は、公開した記事を、修正・整理・削除のために編集することがあります。
4. 投稿者の GitHub のユーザー名と、投稿の内容・日時は、GitHub 上の履歴として公開されます。履歴は後から消すことが難しいため、投稿の前によく確認してください。

## 第3条 禁止事項

次の内容の投稿や、次の行為を禁止します。

1. 法律や公序良俗に反するもの
2. 他人の著作権・肖像権・プライバシーなどの権利を侵害するもの（無断転載を含む）
3. 個人情報（本名、住所、連絡先、学校、顔写真など）や、プレイヤーの拠点の座標などを、本人の同意なく公開するもの
4. 誹謗中傷、差別、脅迫、嫌がらせにあたるもの
5. チート・不具合の悪用など、VoiceMC のルールに違反する行為をすすめたり、そのやり方を広めたりするもの
6. 宣伝・勧誘・スパム、外部のサイトへ誘導することを目的とするもの
7. 他人や運営になりすますもの、わざとうその情報や誤解をまねく情報を書くもの
8. 荒らし、意味のない投稿、同じ内容の投稿の繰り返し
9. スクリプトなど、閲覧者に害を与えるおそれのある記述
10. そのほか、運営が不適切と判断したもの

1. 本規約に違反する投稿は、承認しないか、公開後でも削除します。
