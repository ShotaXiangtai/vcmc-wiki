> むずかしい文章が苦手な人は、[[Wikiの書き方（かんたん版）]] を見てください。

この Wiki の記事は **Markdown**（マークダウン）という書き方で書きます。編集画面の上にあるボタンを押すと、よく使う書き方を入れられます。

## 編集から公開までの流れ

1. 読みたいページの「編集」タブを押す（新しいページは左メニューの「新しいページを作る」）
2. 本文を書き、「プレビュー」タブで見た目を確認する
3. 編集画面の下の手順どおりに、本文をコピーして GitHub で提案（プルリクエスト）する
4. 管理者が内容を確認して承認すると公開されます

投稿には GitHub アカウントが必要です。くわしい手順は、画像付きで [[投稿のしかた]] にまとめています。

## よく使う書き方

| やりたいこと | 書き方 |
| --- | --- |
| 見出し | 行の先頭に `## ` を付ける（小見出しは `### `） |
| 太字 | `**太字**` |
| 箇条書き | 行の先頭に `- ` を付ける |
| 番号付きリスト | 行の先頭に `1. ` を付ける |
| 外部リンク | `[表示する文字](https://example.com/)` |
| 画像（X のポスト）・動画（YouTube） | `[[埋め込み:ポストや動画の URL]]`（くわしくは [[画像のルール]]） |
| プレイヤーのスキンの顔 | `[[スキン:MCID]]` |
| コード | 前後を `` ` `` で囲む。複数行なら ```` ``` ```` の行で囲む |

改行はそのまま改行になります。段落を分けたいときは空行を入れてください。

### Wiki 内のページへのリンク

ほかのページへは、ページ名を二重のかっこで囲んでリンクします。

```
[[はじめかた]]
[[はじめかた|入り方はこちら]]
```

2行目のように `|` のあとに文字を書くと、その文字で表示されます。まだ無いページへのリンクは **赤いリンク** になり、押すとそのページを作れます。

### 表

```
| 見出し1 | 見出し2 |
| --- | --- |
| 内容 | 内容 |
```

### 目次

見出しが3つ以上あるページには、自動で目次が付きます。

## ページ名のルール

- 60文字まで
- 使える文字：文字（ひらがな・カタカナ・漢字・英字）、数字、空白、`_` `-` `(` `)` `（` `）` `・` `ー`
- `/` や `.` などの記号は使えません

## 書いてはいけないもの

- ルール違反・荒らし・個人情報・他人を傷つける内容（くわしくは [[利用規約]]）
- ほかのサイトや本からの無断転載（使えるもの・使えないものは [[ライセンス]]）
- script タグや iframe タグなどの HTML、onclick のようなイベント属性、javascript で始まるリンク（投稿できません）

ほかの画像サイトの画像は表示されません。画像は X のポストで貼ってください（[[画像のルール]]）。
