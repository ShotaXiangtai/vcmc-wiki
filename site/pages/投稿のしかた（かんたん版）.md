むずかしい文章が苦手な人のための、投稿のやり方のかんたん版です。
画像つきのくわしい説明は [[投稿のしかた]] にあります。

## ひとことで言うと

**Wiki で書いて、コピーして、GitHub に貼って、ボタンを押すだけ。**

## 用意するもの

- GitHub のアカウント（無料です。13さい以上の人が作れます）

## やり方（5ステップ）

1. 直したいページの「**編集**」を押して、書く。「**プレビュー**」で見た目を確かめる
2. 下にある「**① 本文をコピーする**」→「**② GitHub の編集画面を開く**」を押す

![「本文をコピーする」と「GitHub の編集画面を開く」のボタン](img/guide/1-copy.png)

3. 初めてのときだけ、緑の「**Fork this repository**」を押す
4. GitHub で、全部えらんで（Ctrl+A）貼り付け（Ctrl+V）。緑の「**Commit changes...**」→「**Propose changes**」を押す

![貼り付けて「Commit changes...」を押す](img/guide/3-paste.svg)

5. 緑の「**Create pull request**」を押す。説明のところの `[ ]` を3つとも `[x]` に変えて、もう一度「**Create pull request**」を押す

![確認の3つにチェックして「Create pull request」を押す](img/guide/6-pr.svg)

これで投稿できました！ 運営がチェックして OK なら、数分で Wiki にのります。
